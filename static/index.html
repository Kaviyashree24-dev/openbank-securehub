REQUEST PATH

App ➔ Gateway ➔ Mock Banking Core

1. Developer / Partner App registers on Developer Portal and requests API access.
2. Developer Portal delivers documentation, sandbox credentials, and dashboard.
3. API Gateway handles incoming requests, routes endpoints (/v1), and enforces rate limits.
4. Auth & Consent Checks verifies bearer token/API key, validates active customer consent, and rejects unauthorized calls (401/403).
5. Mock Banking Services queries synthetic banking ledger (accounts, balances, transactions, and payments).
6. Database records transactions and updates customer account balances.

MONITORING & AI PATH

Telemetry ➔ IsolationForest ➔ Admin Feedback Loop

1. API Activity Logs: Every request is recorded with client ID, endpoint, HTTP status, and latency.
2. Monitoring Module: Aggregates traffic patterns, error ratios, and latency deviations.
3. AI Anomaly Service: Scikit-Learn IsolationForest evaluates sliding-window vectors and scores anomalous behavior.
4. Admin Alert: Generates real-time security alerts with severity (CRITICAL, HIGH, MEDIUM).
5. Feedback Loop: Admin clicks "Suspend Test Key", immediately updating application status to block future requests at Auth & Consent Checks!
